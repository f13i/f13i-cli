# Skills — the f13i specialist library

Each folder is a [Claude Code](https://claude.com/claude-code) skill: a `SKILL.md`
that encodes one workflow I used to do by hand, plus any reference files it needs.
They're invoked by the **Zelia** orchestrator (see the repo
[README](../README.md)) or directly by name.

They read and write my real systems of record — Obsidian, Granola, Gmail, Beehiiv —
so there's no separate database to keep in sync. They're published here as a
**reference architecture**: written against my own vault layout, not a drop-in
product. Any client and personal details in the examples have been replaced with
placeholders.
