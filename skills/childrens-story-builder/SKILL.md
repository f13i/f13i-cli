# Children's Story Builder

Produces a polished, illustrated children's story as a self-contained HTML file. The output matches the quality bar set by "The Moon Who Said Hello": animated starfield or scene background, emoji illustration panels per page, color-highlighted lesson phrases, dialogue callout boxes, floating animations, and a personal dedication.

---

## Step 1: Gather Inputs

If the user hasn't specified, ask (combine into one message — never more than 2 questions):

1. **Theme / lesson** — e.g. kindness, courage, sharing, curiosity, perseverance, honesty
2. **Child's name + age** — for the dedication and age-appropriate vocabulary

If they've already provided these (e.g. "write a story about courage for a young child"), skip asking and proceed directly.

**Age vocabulary guide:**
- 0–2: Very short sentences, simple words, lots of repetition
- 3–5: Simple sentences, concrete concepts, humor and sound words
- 6–8: Richer vocabulary, cause-and-effect, subtle emotional nuance ← default for a young child
- 9–12: More complex plot, internal conflict, layered themes

---

## Step 2: Story Design (internal — don't narrate this to the user)

Before writing, commit to:

**Characters**: 1 main character + 2–3 supporting characters they help. Each encounter illustrates the theme differently. Good archetypes: lonely → connected, scared → brave, selfish → generous, curious → wise.

**Structure** (12 pages):
- Pages 1–2: Introduce main character + their problem/gift
- Pages 3–4: First encounter — character acts on the theme
- Pages 5–6: Reaction + small reward (emotional, not material)
- Pages 7–8: Second encounter — harder version of the same challenge
- Pages 9–10: Third encounter — the hardest moment; character almost fails but chooses the theme anyway
- Pages 11–12: Resolution + thematic payoff stated in the character's own realization

**Scene palettes** (pick 4–5 for variety across pages):
- Night: `linear-gradient(160deg, #1a1a3e 0%, #2d1b4e 50%, #1e3a5f 100%)`
- Morning: `linear-gradient(160deg, #fde68a 0%, #fb923c 40%, #f472b6 100%)`
- Garden/forest: `linear-gradient(160deg, #d1fae5 0%, #a7f3d0 50%, #6ee7b7 100%)`
- Rain: `linear-gradient(160deg, #93c5fd 0%, #6366f1 50%, #4338ca 100%)`
- Sunset: `linear-gradient(160deg, #fed7aa 0%, #fb923c 40%, #dc2626 100%)`
- Stars: `linear-gradient(160deg, #0d0d2b 0%, #1e1b4b 50%, #312e81 100%)`
- Ocean: `linear-gradient(160deg, #bae6fd 0%, #0284c7 50%, #075985 100%)`
- Mountain: `linear-gradient(160deg, #e0e7ff 0%, #6366f1 40%, #312e81 100%)`

## Step 3: Write the HTML

Output a **single self-contained HTML file** using the exact structure below. Do not simplify — use all components.

### Required HTML components

**Fonts**: Always load from Google Fonts:
```
Lora (serif, for story body + title + dialogue)
Nunito (sans-serif, for UI chrome)
```
Pick a DIFFERENT font pair for each story to avoid sameness. Good alternatives: `Playfair Display + Poppins`, `DM Serif Display + DM Sans`, `Cormorant Garamond + Jost`.

**Color variables**: Define in `:root`. Always include:
- A dark background (`--bg`)
- A warm accent (`--accent`) — used for `<strong>` lesson phrases
- A muted accent (`--accent-muted`) — used for `<em>` emotional beats
- A dialogue highlight (`--dialogue-bg`, `--dialogue-border`)
- Page card background: always `#fef9f0` (warm cream)

**Title page**: Centered, with an SVG illustration of the main character or a thematic symbol. Animate it with `float` keyframe. Include `<h1 class="book-title">` and `<p class="dedication">`.

**Starfield or background effect**: Generated by JS — 60–90 dots, random size/position/twinkle duration. Match to story's world (stars for night stories, leaves for forest, bubbles for ocean).

**Pages**: Each page is a `.page` div with:
- A `.scene` div (200px tall, border-radius 16px, gradient background matching the moment's mood)
- Emoji cluster inside the scene — 3–6 relevant emoji, some with `floating-emoji` animation
- `<p class="story-text">` for narrative prose
- `<div class="dialogue">` for any spoken lines (use for ALL dialogue — never inline)
- `<div class="page-number">` absolute positioned bottom-right

**Color rules** (non-negotiable):
- `<strong>` = accent color (lesson/theme words) — e.g. "kindness", "brave", "listened"
- `<em>` = muted accent (emotional beats, internal thoughts, sound words)
- Dialogue box = lavender/purple gradient bg + colored left border

**Animations required**:
- `float` — title SVG bobs up and down
- `twinkle` — background particles
- `pageFade` — each `.page` fades in on load with staggered `animation-delay`
- `drift` — floating emoji in scene panels move independently

**The End page**: Centered, large gold title, italic dedication line referencing the child by name.

### Page text guidelines

- Each page: 2–5 sentences of story text + optional dialogue box
- Vary sentence length — short punchy sentences after emotional peaks
- The lesson should emerge through *action and reaction*, never stated by narrator
- The character states the lesson themselves on page 11 or 12, naturally
- Read-aloud rhythm: read your prose aloud mentally — it should flow smoothly

---

## Step 4: Deliver

1. Save to `/mnt/user-data/outputs/[child-name]-story.html`
2. Call `present_files` with the path
3. Follow with a one-line note: what the lesson moment on page 11/12 is, so the parent knows what to emphasize when reading aloud

---

## Quality checklist (run mentally before saving)

- [ ] 12 pages (not fewer)
- [ ] Every page has a scene panel + story text
- [ ] All dialogue in `.dialogue` boxes, not inline
- [ ] `<strong>` used for lesson/theme words throughout
- [ ] `<em>` used for emotions and internal thoughts
- [ ] At least 4 different scene gradients used
- [ ] SVG title illustration present and animated
- [ ] Starfield or ambient background effect present
- [ ] Personal dedication includes child's name
- [ ] The lesson is shown through action, not told by narrator
- [ ] File saves and presents cleanly
